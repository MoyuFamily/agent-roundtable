5 给码飞的开发提示

关键实现细节，帮助前端快速对接

头像系统

  • 头像用 background: var(--agent-N) 纯色填充
  • 取发言人名字的第一个汉字
  • 状态点：绝对定位右下角，border 遮盖头像边缘
  • 发言中状态：CSS animation + box-shadow 脉动
  • 新增 .style-ring-active 给当前轮次发言者

收敛度

  • 数据源：roundtable_status() 返回 convergence_score
  • SVG 圆环用 stroke-dashoffset 控制进度
  • 色阶：红(低) → 黄(中) → 绿(高) → 蓝(达成)
  • 紧凑版用线性进度条（8px 高），详细版用径向仪表盘
  • 讨论结束后固定显示最终收敛度，不需要动画
